# Design: Retheme Invitation to Wekita-Style Layout (Forest Green & Cream)

**Date**: 2026-11-22
**Status**: Approved in conversation, pending written review
**Branch**: work on `main`; previous version preserved in `backup/tema-dreamy-v1` (commit `327bb15`)

---

## 1. Intent

The bride (Rika) asked for the invitation to look like the reference
<https://by.wekita.id/ilhan-serli/?to=anggi%20permana>. The reference uses a
red/maroon palette that matches that couple's outfits. Rika & Ibnu's photos are
mostly black-and-white studio shots, plus moody teal-green outdoor shots and two
photos with maroon tops. The retheme keeps the reference's layout, ornament style
and section flow, but uses a forest-green and cream palette that suits these photos.

**Success criteria**

- A guest opening the link on a phone gets the same overall impression as the
  reference: watercolor header, capsule photo frame, botanical sketch corners,
  gold sand strips, alternating dark blocks and cream cards.
- All existing features keep working: `?to=` guest name, music, countdown,
  Google Maps and Calendar links, copy bank account, gift address, RSVP & wishes
  stored in Supabase with realtime updates, WhatsApp OG preview.
- No asset copied from wekita.id.
- Tests, typecheck and production build pass. Visual result reviewed by the user
  from screenshots before it is pushed to `main`.

**Decisions made with the user**

| Topic | Decision |
|---|---|
| Implementation approach | Retheme in place: keep data, hooks, Supabase logic; rewrite the visual layer |
| Palette | Forest green + cream + muted gold |
| Ornament assets | Generated by Claude (AI image generation + sharp recolor), reviewed by the user before use |
| Bride/Groom photos | Cropped from the couple's studio photo (no solo photos exist) |
| Bottom floating navbar | Removed (the reference has none) |
| Order of couple | Bride first, then Groom (unchanged from current site) |

**Out of scope**: live streaming, changing the music, rewriting content text
(verse, love story, names), Supabase schema changes.

## 2. Section Flow

The page is a single column locked to phone width (`max-w-[440px]`, centered).
On wider screens the area outside the column shows a blurred forest-green background.

| # | Section | Content | Background |

| 2 | Quote | QS. Ar-Rum: 21 | Forest block |
| 3 | Couple | Bride card, then Groom card: cropped photo with script name overlay, full name, parents, order in family, Instagram link | Cream with leaf corners |

## 3. Visual System

### 3.1 Color tokens

Added under `theme.extend.colors` in `tailwind.config.ts`. The old `dreamy`,
`primary` and `champagne` tokens and all raw hex values in components are removed.

| Token | Hex | Use |
|---|---|---|
| `forest-900` | `#1F3A34` | Dark blocks, primary buttons |
| `forest-700` | `#2E4F47` | Hover, gradients |
| `cream-50` | `#F5EFE4` | Cards, light background |
| `cream-100` | `#EDE4D3` | Borders, inputs, image placeholders |
| `gold-500` | `#B89B5E` | Couple names, dividers, icons |
| `ink` | `#1C2A26` | Body text on cream |
| `sage-500` | `#6B7F73` | Secondary text, ornaments |

### 3.2 Fonts (Google Fonts via `next/font`)

| Role | Font | Example |
|---|---|---|
| Display, uppercase titles | Cinzel | "RIKA & IBNU", "AKAD NIKAH" |
| Elegant italic | Cormorant Garamond | Full names, verse |
| Script accent | Pinyon Script | "*The Date*", "*Our Gallery*", name on photo |
| Body, forms, labels | Quicksand | Paragraphs, inputs |

DM Sans and Alex Brush are removed.

### 3.3 Generated assets

Stored in `public/themes/forest/`, WebP with transparency. Each one is shown
to the user for approval before it is used.

1. `watercolor-top.webp`: forest-green watercolor wash that fades to transparent at the bottom (cover, hero).
2. `leaf-left.webp`, `leaf-right.webp`: line-art sketch of dry leaves and grass in sage (card corners).
3. `gold-sand.webp`: glittering gold sand strip, transparent at the top (card bottoms, cover).
4. `sprig.webp`: small sprig of leaves (ornament above card titles).
5. `outer-bg.webp`: blurred forest background for the area outside the column on desktop.

### 3.4 Motion

- `FadeUp` scroll reveal (existing).
- Slow `sway` on leaf corners (existing keyframe).
- Up to 12 floating white sparkle dots on forest blocks, CSS only.
- All motion is disabled under `prefers-reduced-motion: reduce`.

   couple photo; Resepsi uses the walking hand-in-hand photo; Closing uses a
   black-and-white studio photo. The final mapping is shown to the user as a
   contact sheet for approval.
4. Regenerate `public/og-image.jpg` (1200×630) with the new palette.

## 5. Error Handling and Edge Cases

- Image fails to load: the frame keeps its size and shows `cream-100`; layout does not shift.
- Supabase failure: unchanged behavior (red error message, list not modified).
- Pagination: arrows disabled on the first/last page; hidden when there is one page or none.
- Very long `?to=` name: wraps with `break-words`, clamped to 2 lines on the cover.
- Audio blocked by the browser: button shows the paused state, no error surfaced.
- `prefers-reduced-motion`: sparkles, sway and fade-up disabled.
